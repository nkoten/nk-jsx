# nk-jsx

An elegant, dark-themed collection of React components built for personal use. Inspired by the minimalism of shadcn/ui and tailored for rapid development.

## 🌌 Overview

**nk-jsx** is my personal component library designed to streamline the way I build React applications. Instead of a heavy npm package, this project focuses on copy-pasteable components that I can fully control and customize.

- **Developer:** Anselmo Sammarco (Céo)
- **Tech Stack:** React (JSX), Tailwind CSS, Framer Motion.
- **Philosophy:** Clean code, accessibility, and a "Dark-First" design language.

## 🏗️ Project Status

This is a **personal library** under constant evolution. I am building this as part of my journey in Software Engineering to centralize my favorite UI patterns and logic.

## 🚀 Key Features

*   **Dark Mode by Default:** Optimized for high-contrast, elegant dark interfaces.
*   **Zero Installation:** Components are meant to be copied directly into your project.
*   **Fully Customizable:** Since you own the code, you change the styles to fit your needs.
*   **Software Engineering Standards:** Developed with scalability and clean architecture in mind.

## 🛠️ Usage

Since this is a collection of `.jsx` components, simply navigate to the `components` folder, find the one you need, and drop it into your project:

```bash
# Example: Adding a Button component
# Copy components/ui/Button.jsx to your project
```
